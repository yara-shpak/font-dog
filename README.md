# Font Dog — точкові шрифти

Інструмент для малювання dot-matrix шрифтів на сітці (за замовчуванням 5×7 + 2 рядки під базовою лінією) з експортом в OTF і WOFF2.

**Онлайн:** https://yara-shpak.github.io/font-dog/

## Запуск

Відкрийте посилання вище або `index.html` у Chrome. Потрібен інтернет: GSAP, opentype.js, шрифти інтерфейсу і Brotli (для WOFF2) вантажаться з CDN.

Або через локальний сервер:

```bash
python3 -m http.server 5178
```

і відкрийте http://localhost:5178.

## Як працює

1. **Новий шрифт** — назва, сітка, мови й набори символів (латиниця, кирилиця, цифри, знаки, власні гліфи), старт із заготовками або з чистого аркуша.
2. **Малювання** — клік по клітинці додає або прибирає точку, протягування малює лінію. Кожна зміна одразу зберігається в браузері (localStorage).
3. **Налаштування** праворуч діють на весь шрифт або, в режимі «Лише «A»», тільки на поточний гліф.
4. **Сімейство** — «+» біля назви накреслення копіює поточне (Light, Bold…) і може підлаштувати товщину обведення під вагу. Малюнок гліфів спільний для всього сімейства, а параметри точок у кожного накреслення свої.
5. **Експорт** — назва сімейства, накреслення, формати OTF / WOFF2.

## Клавіші

| Дія | Клавіші |
| --- | --- |
| Попередній / наступний гліф | ← / → |
| Перейти до гліфа | набрати символ |
| Зсунути гліф | ⇧ + стрілки |
| Очистити гліф | Delete |
| Копіювати / вставити гліф | ⌘C / ⌘V |
| Скасувати / повторити | ⌘Z / ⇧⌘Z |

## Структура

- `js/templates.js` — заготовки 5×7 для всіх символів
- `js/charset.js` — набори, вкладки, генерація під будь-яку сітку
- `js/geometry.js` — точки, овали, threshold-текстура, метрики
- `js/editor.js`, `js/glyphs.js`, `js/controls.js`, `js/tester.js` — частини інтерфейсу
- `js/export.js` — OTF через opentype.js і власний пакувальник WOFF2
